# Welcome

JezzWTF QoL Nodes adds utilities, character chat, LoRA and model loaders, MiniMax H3 RefMod, GIF tools, a Run Timer and a clipboard Paste Stack to ComfyUI.

This window is the pack's help. Pick a topic on the left, or search for a node name or a problem at the top.

## Quick links

- [Where files are saved](topic:saved-files) is the answer to "where did my file go?"
- [Example workflows](topic:example-workflows) lists the ready-made graphs you can open from the Workflows window.
- [Troubleshooting](topic:troubleshooting) covers the common errors.

## Opening the windows

Both are floating panels that never block the canvas. Use the **Workflows** and **Docs** buttons in ComfyUI's top bar, press **Alt+Shift+W** or **Alt+Shift+D**, or use the canvas right-click menu and the command palette (search for "JezzWTF").

> Nodes in this pack never carry long explanations on the node itself. They live here.
