# Documentation window

A floating panel, like Paste Stack, so you can read while you work.

- Click **Docs** in ComfyUI's top bar, press **Alt+Shift+D**, use the canvas right-click menu, or run "JezzWTF Documentation" from the command palette.
- Drag the title bar to move it and the corner to resize it. It remembers its place and whether it was open.
- Pick a topic in the tree. Sections collapse.
- Search covers every topic and shows a snippet for each hit.
- **Copy as text** copies the current page.
- It reopens on the last topic you read. **Esc** hides it.
