# Text nodes

## Text Box

A reusable prompt card that outputs a string. It shows live character and word counts, with **Copy** and **Clear** buttons.

## Text Encode (Zero Negative)

Encodes your positive prompt and builds the negative in the same node. `negative_mode` is either **Zero Out** (a zeroed conditioning, like the core ConditioningZeroOut node) or **Empty String** (an empty prompt encoded normally).

## Title Font

A styled title banner for organising workflows. Pick a style, glow, animation and colour preset.

## Edit Prompt Template

Combines an edit instruction with an optional suffix and separator, for edit models that want a fixed phrasing.
