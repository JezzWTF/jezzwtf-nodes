# Model Preview Mirror

Pass a value through and show a sampler's live preview beside it. Connect the model the sampler uses to follow that sampler, or leave it unconnected to follow any preview.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `any` | Optional. A MODEL that has a JezzWTF or KJNodes sampler preview attached makes the panel follow that sampler; any value passes straight through. | * | No |  |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `any` | The input value, unchanged. | * |

Notes:

- More detail, including how this node fits with the others, is in the guide of the JezzWTF Documentation window (Alt+Shift+D).
