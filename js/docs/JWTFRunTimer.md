# Run Timer

A display of the current and last run time. Every run is timed whether or not this node is on the canvas; renaming it labels its runs.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `label` | Label under which this node files its runs, populated from the node title by the frontend. | STRING | No |  |

Notes:

- More detail, including how this node fits with the others, is in the **Welcome** page of the JezzWTF Documentation window (Alt+Shift+D).
