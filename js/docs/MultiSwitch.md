# Multi Switch

Route several values by one switch.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `switch` | Option A → false_N inputs pass through.  Option B → true_N inputs pass through. (default: false) | BOOLEAN | Yes |  |
