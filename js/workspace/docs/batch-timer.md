# Batch Timer and Refresh Page

## Batch Timer

Counts finished items across queued prompts, for batch runs. It shows progress, the average time per item and an ETA, and resumes after a page reload. For timing a single whole run, use [Run Timer](topic:run-timer) instead.

## Refresh Page (VRAM Cleaner)

A pass-through node that frees VRAM and can reload the page. It shows a VRAM gauge and buttons for clean, refresh and reload.
